Language Translation App

## Project Overview
This project is a Language Translation application developed as part of my CodeAlpha internship.  
It enables users to translate text from one language to another using a simple and interactive web interface built with Streamlit.

The application uses translation services powered by Google Translate through the Deep Translator library.

---

## Features
- Translate text between multiple languages
- Simple and interactive Streamlit UI
- Fast and accurate translation results
- Supports multiple global languages
- Uses Google Translate API internally via Deep Translator

---

## Technologies Used
- Python 
- Streamlit
- Deep Translator (uses Google Translate service internally)
---
